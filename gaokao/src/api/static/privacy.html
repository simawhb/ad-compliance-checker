隐私政策

最后更新：2026年7月4日

一、信息收集

驷马报考（以下简称"本平台"）仅在您主动使用时收集以下信息：

1. 您输入的高考分数、选科组合等查询参数（仅用于生成志愿推荐，不会持久化存储）。

2. 霍兰德性格测试的答案选择（仅用于当次性格分析，不会存储个人答案）。

3. 服务器日志会自动记录匿名化的访问时间、请求路径、状态码。日志中不包含个人身份信息。

二、信息使用

收集的信息仅用于以下目的：

1. 提供高考志愿填报数据查询服务。

2. 优化平台的数据质量和用户体验。

3. 生成匿名的使用统计（如热门查询专业、院校对比频率等）。

我们不会将您的信息出售、出租或分享给任何第三方。

三、数据来源声明

本平台的院校和录取数据来源于：

1. 教育部官方公布的全国高等学校名单。

2. 各省教育考试院公开发布的高考录取数据和省控线。

3. B站、知乎等平台的公开口碑信息（仅展示，不修改原意）。

4. 智联招聘等公开平台的薪资统计（仅展示宏观统计数据）。

所有数据均来自合法公开渠道，如有侵权请联系我们删除。

四、免责声明

本平台提供的所有数据仅供参考，不构成任何形式的志愿填报建议。

高考志愿填报应以各省教育考试院官方公布的数据和信息为准。

使用本平台即表示您理解并同意：平台不对因使用数据而产生的任何决策后果承担责任。

五、第三方服务

本平台的 AI 问答功能调用 DeepSeek API 提供服务。您的问题将被发送至 DeepSeek 处理，但我们不会分享您的个人身份信息。

此外，本平台使用 Vue.js（CDN 加载）进行前端渲染，不加载其他第三方追踪脚本。
