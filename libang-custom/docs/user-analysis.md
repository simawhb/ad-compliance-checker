# 驷马合规·目标用户分析与部署方案

## 一、目标用户画像

### 1. 电商商家（最大群体）
- 淘宝/京东/拼多多/抖音小店商家
- 痛点：商品详情页频繁因违禁词被平台下架、罚款
- 典型场景：上架前自查、大促活动页审查、直播话术审查
- 付费意愿：高（一次罚款几百到几万，工具几十块就能避免）
- 使用频率：每天多次

### 2. 化妆品/保健品品牌方
- 化妆品公司市场部、品牌部
- 痛点：功效宣称拿不准边界，备案和宣传用语容易踩红线
- 典型场景：新品上市宣传文案审查、详情页合规检查
- 付费意愿：很高（行业监管严格，处罚力度大）
- 使用频率：每周几次

### 3. 自媒体/MCN/直播机构
- 抖音/小红书/快手博主、MCN机构
- 痛点：直播间口播、短视频脚本容易违规，被限流甚至封号
- 典型场景：直播话术预审、短视频文案检查
- 付费意愿：中等
- 使用频率：每天

### 4. 广告公司/营销代理
- 4A公司、本地广告公司
- 痛点：客户广告被驳回或处罚，需要内部审查流程
- 典型场景：广告创意出街前内部审查
- 付费意愿：高（可以转嫁给客户）
- 使用频率：每天多次

### 5. 中小企业主
- 餐饮、教培、美容院等
- 痛点：朋友圈广告、传单、门店海报不知道哪些词不能用
- 典型场景：促销活动文案自查
- 付费意愿：中低（价格敏感）
- 使用频率：偶尔

## 二、核心痛点排序

1. **罚款恐惧** — 广告法罚款起步就是几万到几十万，商家最怕的就是踩雷
2. **规则复杂** — 广告法+行业规范+平台规则叠加，普通人根本记不住
3. **效率低下** — 人工审查慢、找律师贵、自己查法条不专业
4. **时效性** — 法规和平台规则频繁更新，老的违禁词表不够用
5. **多平台适配** — 淘宝/抖音/小红书各有自己的规则，需要逐一适配

## 三、差异化定位

### 竞品分析
| 产品 | 优势 | 不足 |
|------|------|------|
| 平台自带检测 | 免费、规则准确 | 只覆盖自家平台，不通用 |
| 违禁词查询网站 | 免费 | 只有词库，无语义分析 |
| 律师人工审查 | 专业准确 | 贵（几百到几千/次）、慢 |
| 通用AI（ChatGPT等） | 灵活 | 不够专业，容易遗漏 |

### 我们的优势
- 专业法律背景（驷马说法背书）
- 规则引擎+AI双引擎（快速+深度）
- 化妆品/食品等垂直行业深度适配
- 持续更新的知识库（法规+案例）
- 价格亲民（相比律师费）

## 四、商用部署方案

### 4.1 架构设计
前端：微信小程序 + Web端（响应式）
后端：Python FastAPI + SQLite → 后期可迁移PostgreSQL
用户系统：微信授权登录（小程序）+ 手机号（Web端）
支付：微信支付（小程序）+ 支付宝（Web端）
LLM：MiMo v2.5 Pro（会员用户由站长承担费用）
数据：检测文案不保存原文，只保存脱敏后的统计数据
初期：单机部署，100用户并发完全够用

### 4.2 会员体系
免费版：每天5次快速检测，无深度分析
专业版：99元/月，100次/天快速+20次/天深度
企业版：299元/月，不限次数+API接口+专属客服
年付优惠：打8折

### 4.3 微信小程序要点
- 需要注册小程序账号（企业主体）
- 需要ICP备案（用于后端域名）
- 微信支付需要商户号
- 类目选择：工具 > 信息查询
- 服务器域名需要HTTPS

### 4.4 推广策略
- 驷马说法公众号导流（私域）
- 抖音/小红书发广告法科普内容（引流）
- 电商商家社群推广（精准）
- 首月免费试用（拉新）
- 老用户推荐返佣（裂变）
