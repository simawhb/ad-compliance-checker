## 四、企业定制版配置说明

### 访问方式

通过 Nginx `auth_basic` 密码保护访问，支持用户名/密码认证。

### 接入步骤

1. 联系获取访问密码（用户名 + 密码）
2. 访问 https://4ma.wang/ad-check/
3. 输入凭证即可使用全部功能

### 定制项

可根据企业需求定制：

- 检测规则（行业特定违禁词库）
- 报告模板（企业品牌信息）
- 使用配额（不限或指定额度）
- 数据保留期限

## 五、技术说明

企业定制版与公开版共享同一套 AI 检测引擎，但：

- 数据库独立，企业数据与其他用户隔离
- 运行在独立进程中（端口 8001）
- 通过 Nginx 做反向代理和访问控制
- 部署在同一台服务器或独立服务器
